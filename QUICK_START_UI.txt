📋 ÉTAPES SIMPLES (2 minutes)

1. Ouvrez votre scène principale dans Godot

2. Ajoutez un Node :
   ┌─────────────────────────────────────┐
   │ Clic droit → Add Child Node → Node │
   │ Nom : "CraftingUIManager"           │
   └─────────────────────────────────────┘

3. Attachez le script :
   ┌───────────────────────────────────────────────────┐
   │ Sélectionnez "CraftingUIManager"                  │
   │ Inspecteur → Script → Load                        │
   │ → res://Scripts/CraftingUIManager.gd              │
   └───────────────────────────────────────────────────┘

4. Lancez le jeu et appuyez sur C !

❌ "Player non trouvé"
   → Vérifiez que Player.gd contient : add_to_group("player")

❌ L'UI ne s'ouvre pas
   → Vérifiez que CraftingUIManager.gd est bien attaché

❌ Erreur de chargement de scène
   → Vérifiez que CraftingUI.tscn existe dans Scenes/
